We are proud to announce the **official launch (v1.0.0)** of the P2P Lending Platform! 🚀

This release marks the completion of our core banking integration and blockchain audit layer.

<!--truncate-->

## 🌟 Key Highlights

### 1. Core Banking Engine (Apache Fineract)
We have fully integrated **Apache Fineract** to handle the heavy lifting of financial calculations.
*   **Double-Entry Accounting**: Every penny is tracked.
*   **Interest Calculation**: Automated Daily/Monthly interest accrual.
*   **Fixed Deposit Module**: Auto-invest feature for lenders.

### 2. Immutable Audit Trail (Hyperledger Fabric)
Trust is paramount. We've deployed a private **Hyperledger Fabric** network to audit critical actions:
*   Loan Applications.
*   Disbursement Events.
*   Repayment Logs.

### 3. Smart Reconciliation
No more manual spreadsheets! Our **Reconciliation Service**:
*   Auto-matches Fineract transactions with P2P contexts.
*   Handles **Fuzzy Matching** for edge cases (date/amount variance).
*   Calculates **Admin Spread** (Profit) in real-time.

### 4. Cross-Platform Mobile App
*   Built with **React Native & Expo**.
*   **Glassmorphism UI**: A stunning, modern interface.
*   Real-time notifications for Loan Matches.

## 🐛 Bug Fixes
*   Fixed "Phân phối gốc & lãi" log missing in Fineract UI.
*   Resolved Profit Calculation formula to correctly account for Admin Spread.

## 🔜 What's Next?
*   **v1.1**: AI-powered Credit Scoring integration.
*   **v1.2**: Secondary Market for selling Loan Notes.
