## 1. TỔNG QUAN

### 1.1. Yêu Cầu Đầu Vào

**API Endpoint:**
```
POST /fineract/signup
hoặc
POST /auth/signup
```

**Request Body:**
```json
{
  "firstName": "Nguyễn",
  "lastName": "Văn A",
  "phoneNumber": "0987654321",
  "email": "nguyenvana@gmail.com",  // Optional
  "password": "Password123!@#",
  "isBusiness": false,  // true nếu là doanh nghiệp
  "userType": "borrower"  // "borrower" hoặc "lender"
}
```

### 1.2. Password Requirements (QUAN TRỌNG!)

Fineract yêu cầu mật khẩu **RẤT CHẶT**:

✅ **Phải có:**
- Độ dài: 12-50 ký tự
- Ít nhất 1 chữ HOA (A-Z)
- Ít nhất 1 chữ thường (a-z)
- Ít nhất 1 chữ số (0-9)
- Ít nhất 1 ký tự đặc biệt (!@#$%^&*)

❌ **Không được:**
- Chứa khoảng trắng
- Có ký tự lặp liên tiếp (aa, bb, 11, 22...)

**Ví dụ hợp lệ:**
```
Password123!@#
SecurePass2024#$
MyP@ssw0rd456!
```

**Ví dụ KHÔNG hợp lệ:**
```
12345678        ← Thiếu chữ cái, ký tự đặc biệt
Password        ← Thiếu số, ký tự đặc biệt
Pass 123!       ← Có khoảng trắng
Passwword123!   ← Có ký tự lặp liên tiếp (ww)
password123!    ← Thiếu chữ HOA
```

### 1.3. Flow Diagram

```
┌─────────────┐
│ Client App  │
│ (Register)  │
└──────┬──────┘
       │ POST /fineract/signup

       ↓
┌──────────────────────┐
│ Server Controller    │

       │
       ↓
┌────────────────────────────────────────────┐
│ FineractSignupService.signup()             │
├────────────────────────────────────────────┤
│                                            │
│ Step 1: Create Fineract CLIENT             │

│    └─ POST /fineract/clients/{id}?activate│
│                                            │
│ Step 2: Create SAVINGS ACCOUNT            │
│    ├─ POST /savingsaccounts                │

│    └─ POST /savingsaccounts/{id}?activate  │
│                                            │
│ Step 3: Create Fineract USER               │
```

### STEP 1: TẠO FINERACT CLIENT

**Purpose:** Tạo profile khách hàng (lender or borrower) trên Fineract

#### 1.1. Create Client
```http
POST http://118.69.41.95:8080/fineract-provider/api/v1/clients
Authorization: Basic bWlmb3M6cGFzc3dvcmQ=
Content-Type: application/json

{
  "firstname": "Nguyễn",
  "lastname": "Văn A",
  "mobileNo": "0987654321",
  "externalId": "0987654321",
  "officeId": 1,
  "legalFormId": 1,  // 1 = Person, 2 = Entity/Business
  "active": false,
  "submittedOnDate": "21 December 2025",
  "dateFormat": "dd MMMM yyyy",
  "locale": "en_US"
}
```

**Response:**
```json
{
  "officeId": 1,
  "clientId": 5,
  "resourceId": 5
}
```

**Lưu ý:**
- `externalId` = username (SĐT) để dễ query sau này
- `legalFormId`: 1 = cá nhân, 2 = doanh nghiệp
- `active: false` vì cần activate riêng

```http

Content-Type: application/json

{
  "activationDate": "2025-12-21",
  "locale": "en",
  "dateFormat": "yyyy-MM-dd"
}
```

**Response:**
```json
{
  "officeId": 1,
  "clientId": 5,
  "resourceId": 5,
  "changes": {
    "status": { "id": 300, "value": "Active" }
```

## 3. VALIDATION & ERROR HANDLING

### 3.1. Password Validation

**Code:**
```javascript
function _validatePassword(password) {
  // Kiểm tra độ dài
  if (password.length < 12 || password.length > 50) {
    return { valid: false, message: 'Mật khẩu phải từ 12 đến 50 ký tự' };
  }
  
  // Kiểm tra khoảng trắng
  if (/\s/.test(password)) {
    return { valid: false, message: 'Mật khẩu không được chứa khoảng trắng' };
  }
  
  // Kiểm tra ký tự lặp liên tiếp
  if (/(.)\ 1/.test(password)) {
    return { valid: false, message: 'Mật khẩu không được có ký tự lặp lại liên tiếp' };
  }
  
  // Kiểm tra ít nhất 1 số
  if (!/\d/.test(password)) {
    return { valid: false, message: 'Mật khẩu phải có ít nhất 1 chữ số' };
  }
  
  // Kiểm tra ít nhất 1 chữ thường
  if (!/[a-z]/.test(password)) {
    return { valid: false, message: 'Mật khẩu phải có ít nhất 1 chữ thường' };
  }
  
  // Kiểm tra ít nhất 1 chữ HOA
  if (!/[A-Z]/.test(password)) {
    return { valid: false, message: 'Mật khẩu phải có ít nhất 1 chữ hoa' };
  }
  
  // Kiểm tra ít nhất 1 ký tự đặc biệt
  if (!/[^\w\s]/.test(password)) {
    return { valid: false, message: 'Mật khẩu phải có ít nhất 1 ký tự đặc biệt' };
  }
  
  return { valid: true };
}
```

### 3.2. Error Cases

| Error | HTTP Code | Message | Giải pháp |
|-------|-----------|---------|-----------|
| Password không hợp lệ | 400 | "Mật khẩu không hợp lệ: ..." | Sửa password theo yêu cầu |
| Thiếu field bắt buộc | 400 | "Thiếu thông tin bắt buộc" | Gửi đủ firstName, lastName, phoneNumber, password |
| Username đã tồn tại (Fineract) | 409 | "Tài khoản đã tồn tại" | Dùng SĐT khác hoặc login |
| Username đã tồn tại (Keycloak) | 409 | "Tài khoản đã tồn tại" | Tự động lấy existing user ID |
| Fineract service chưa khởi tạo | 503 | "Fineract service chưa được khởi tạo" | Restart server |
| Keycloak connection failed | 500 | "Keycloak error: ..." | Check Keycloak server |
| Request timeout | 504 | "Request timeout" | Retry hoặc check network |

### 3.3. Rollback Strategy

**Câu hỏi:** Nếu step 4 (Keycloak) fail, có rollback Fineract không?

**Trả lời:** KHÔNG!

Lý do:
- Fineract đã tạo xong (Client, Savings, User)
- User có thể login vào Fineract được
- Keycloak chỉ là authentication layer bổ sung
- Có thể tạo Keycloak user sau

**Best Practice:**
- Log chi tiết lỗi Keycloak
- Return success với note: `keycloakUserId: null`
- Admin có thể tạo Keycloak user manual sau

```typescript
  email?: string;
  password: string;
  isBusiness?: boolean;
  userType?: 'borrower' | 'lender';
}

export interface SignupResponse {
  success: boolean;
  statusCode: number;
  message: string;
  data?: {
    clientId: number;
    userId: number;
    savingsId: number;
    username: string;
    keycloakUserId?: string;
  };
}

export const authApi = {
  signup: async (data: SignupRequest): Promise<SignupResponse> => {
    const response = await api.post<SignupResponse>('/fineract/signup', data);
    return response.data;
  },
};
```

### 6.3. Password Validation (Client-side)

```typescript
const validatePassword = (password: string): string | null => {
  if (password.length < 12 || password.length > 50) {
    return 'Mật khẩu phải từ 12 đến 50 ký tự';
  }
  if (/\s/.test(password)) {
    return 'Mật khẩu không được chứa khoảng trắng';
  }
  if (/(.)\ 1/.test(password)) {
    return 'Mật khẩu không được có ký tự lặp liên tiếp';
  }
  if (!/\d/.test(password)) {
    return 'Mật khẩu phải có ít nhất 1 chữ số';
  }
  if (!/[a-z]/.test(password)) {
    return 'Mật khẩu phải có ít nhất 1 chữ thường';
  }
  if (!/[A-Z]/.test(password)) {
    return 'Mật khẩu phải có ít nhất 1 chữ HOA';
  }
  if (!/[^\w\s]/.test(password)) {
    return 'Mật khẩu phải có ít nhất 1 ký tự đặc biệt (!@#$%^&*)';
  }
  return null;
};
```

## TÓM TẮT

**4 Bước Chính:**
1. ✅ Tạo Client trên Fineract → Get clientId
2. ✅ Tạo Savings Account → Get savingsId
3. ✅ Tạo User trên Fineract → Get userId
4. ✅ Tạo User trên Keycloak + Assign Role → Get keycloakUserId

**Kết quả:**
- User có thể login bằng `username` (SĐT) + `password`
- Có savings account để giao dịch tiền
- Được gán role (borrower/lender) trong Keycloak
- Full integration: Fineract + Keycloak + MongoDB

**Password Requirements (QUAN TRỌNG):**
- 12-50 ký tự
- Có chữ HOA, chữ thường, số, ký tự đặc biệt
- Không có khoảng trắng, không lặp ký tự
