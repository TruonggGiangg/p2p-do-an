## 1. LUỒNG VAY TIỀN

### 1.1. Borrower Tạo Khoản Vay

**Input:**
- Borrower: 0329646588
- Số tiền vay: 10,000,000 VND
- Thời hạn: 6 tháng
- Mục đích: Kinh doanh
- Credit score: 650

**Steps:**

#### Step 1: Client App → Server
```
POST /loan/create
{
  "capital": 10000000,
  "periodMonth": 6,
  "willing": "Kinh doanh",
  "creditScore": 650
}
```

#### Step 2: LoanService.createLoan()
```typescript
1. Tính lãi suất dựa trên credit score & period
   rate = calculateInterestRate(650, 6) 
   // Ví dụ: 1.5%/tháng

2. Tính số notes
   noteValue = 500,000 VND (từ .env NOTE_UNIT_PRICE)
   totalNotes = 10,000,000 / 500,000 = 20 notes

3. Tạo contractId
   contractId = "LN_" + timestamp

4. Lưu vào MongoDB
   - status: "waiting" (chờ đầu tư)
   - investedNotes: 0
   - totalNotes: 20
```

#### Step 3: Tạo Loan trên Fineract (nếu FINERACT_LOAN_CREATION=true)
```typescript
FineractService.createLoan():
  1. Resolve borrower's Fineract client ID
     borrowerClientId = resolveClientId("0329646588")
     // Returns: 2

  2. Create loan on Fineract
     POST /fineract-provider/api/v1/loans
     {
       "clientId": 2,
       "productId": 1, // P2P Loan Product
       "principal": 10000000,
       "loanTermFrequency": 6,
       "numberOfRepayments": 6,
       "repaymentEvery": 1,
       "repaymentFrequencyType": 2, // Monthly
       "interestRatePerPeriod": 1.5,
       ...
     }
     
     Response: { loanId: 15, resourceId: 15 }

  3. Lưu fineractLoanId vào MongoDB
     loanContract.fineractLoanId = 15
```

#### Step 4: Blockchain Recording (nếu BLOCKCHAIN_ENABLED=true)
```typescript
BlockchainService.createLoanContract():
  - Ghi loan contract lên Hyperledger Fabric
  - Lưu blockchainTxId
```

**Output:**

## 3. LUỒNG ĐẦU TƯ - PARTIAL MATCH

### 3.1. Scenario: Nhiều lender đầu tư một phần

**Starting State:**
- Loan: LN_xxx (10,000,000 VND, 20 notes)
- totalNotes: 20
- investedNotes: 0

**Investment 1: Lender A đầu tư 30%**

```
Lender A: 0987654321
Amount: 3,000,000 VND (6 notes)

Steps (tương tự Full Match nhưng không trigger disbursement):
1. Create escrow: ESCROW_A (3M, status: waiting)
2. Fund escrow: Lender A → Escrow (3M)
   - escrow status: "funded"
   - txn ID: 800
3. Create investment: INV_A
   - escrowId: ESCROW_A
   - escrowStatus: "funded"
4. Update loan
   - investedNotes: 0 + 6 = 6
   - Check: 6 < 20 → NO disbursement yet

State:
- Loan: investedNotes = 6/20 (30%)
- Escrow ESCROW_A: funded, waiting to be released
- Investment INV_A: status "waiting_other"
```

**Investment 2: Lender B đầu tư 20%**

```
Lender B: 0912345678
Amount: 2,000,000 VND (4 notes)

Steps:
1. Create escrow: ESCROW_B (2M)
2. Fund escrow: Lender B → Escrow (2M, txn: 801)
3. Create investment: INV_B
4. Update loan
   - investedNotes: 6 + 4 = 10
   - Check: 10 < 20 → NO disbursement yet

State:
- Loan: investedNotes = 10/20 (50%)
- Escrows: ESCROW_A (funded), ESCROW_B (funded)
- Waiting for more investors...
```

**Investment 3: Lender C đầu tư 50% → TRIGGER DISBURSEMENT**

```
Lender C: 0923456789
Amount: 5,000,000 VND (10 notes)

Steps:
1. Create escrow: ESCROW_C (5M)
2. Fund escrow: Lender C → Escrow (5M, txn: 802)
3. Create investment: INV_C
4. Update loan
   - investedNotes: 10 + 10 = 20
   - Check: 20 >= 20 → ✓ TRIGGER DISBURSEMENT!

Auto-Disbursement:
1. Approve & Disburse loan on Fineract
2. Find all funded escrows:
   [ESCROW_A (3M), ESCROW_B (2M), ESCROW_C (5M)]

3. Release each escrow → Borrower:
   - Escrow → Borrower: 3M (txn: 803)
   - Escrow → Borrower: 2M (txn: 804)
   - Escrow → Borrower: 5M (txn: 805)
   Total: 10M to borrower

4. Update all:
   - All escrows: status "released"
   - All investments: escrowStatus "disbursed", status "success"
   - Loan: fineractStatus "ACTIVE", disburse_done: true

Final Transactions:
1. Lender A → Escrow: 3M [800]
2. Lender B → Escrow: 2M [801]
3. Lender C → Escrow: 5M [802]
4. Escrow → Borrower: 3M [803]
5. Escrow → Borrower: 2M [804]
6. Escrow → Borrower: 5M [805]

Borrower receives: 3M + 2M + 5M = 10M total
```

## 4. LUỒNG GIẢI NGÂN

(Đã giải thích chi tiết trong Section 2 & 3)

**Summary:**
- **Trigger:** investedNotes >= totalNotes
- **Method:** `InvestService.handleFullMatchDisbursement()`
- **Steps:**
  1. Approve loan on Fineract
  2. Disburse loan on Fineract (status → ACTIVE)
  3. Find all funded escrows for the loan
  4. Release each escrow: Escrow → Borrower
  5. Update escrow status: "released"
  6. Update investment status: "success", escrowStatus: "disbursed"
  7. Update loan: disburse_done = true

## TÓM TẮT FUND FLOWS

### Money Movement Summary

**Investment Phase:**
```
Lender A → Escrow A: 3M
Lender B → Escrow B: 2M
Lender C → Escrow C: 5M
```

**Disbursement (when 100% funded):**
```
Escrow A → Borrower: 3M
Escrow B → Borrower: 2M
Escrow C → Borrower: 5M
Total to borrower: 10M
```

**Repayment (monthly or prepay):**
```
Borrower → Lender A: Principal% + Interest%
Borrower → Lender B: Principal% + Interest%
Borrower → Lender C: Principal% + Interest%
```

**Key Principles:**
1. ✅ All investments go through ESCROW first
2. ✅ Borrower only receives money after 100% funded
3. ✅ Repayments distributed proportionally
4. ✅ All transactions tracked in Fineract + MongoDB
5. ✅ Full audit trail via escrow_logs
